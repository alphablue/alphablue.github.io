<h2 id="starting-point">앱의 질문을 출발점으로</h2>

이 제목은 목록과 본문에서 긴 한글 제목이 줄바꿈되는 모습을 확인하기 위해 길게 작성했습니다. 앞으로 AOSP 글에서는 앱에서 만난 구체적인 질문을 출발점으로 삼고, 소스에서 확인한 경로를 따라가 보는 구성을 생각하고 있습니다.

아래 내용은 글의 형태를 보여주는 샘플입니다. 특정 Android 버전의 실제 호출 경로를 분석한 결과가 아니며, 클래스 이름이나 소스 위치를 검증한 것처럼 표시하지 않습니다.

<h2 id="reading-source">소스를 읽으며 남길 기록</h2>

### 1. 기준점 정하기

어떤 Android 버전과 소스 커밋을 읽고 있는지 먼저 기록할 예정입니다. 글을 읽는 사람이 같은 위치를 찾을 수 있도록 경로와 근거를 연결하는 자리가 필요합니다.

### 2. 경계마다 질문 남기기

| 구간 | 글에서 확인하려는 질문 |
| --- | --- |
| 앱에서 사용하는 API | 호출하는 쪽이 기대하는 동작은 무엇인가? |
| 프레임워크의 구현 | 요청을 처리하는 책임은 어디에 있는가? |
| 시스템과의 연결 | 어떤 경계를 지나며 무엇이 달라지는가? |

이 표는 실제 호출 순서를 확정한 도식이 아니라 분석할 때 던질 질문의 목록입니다. 완성된 글에서는 소스와 실행 근거를 확인한 뒤 단계별 설명을 채울 예정입니다.
