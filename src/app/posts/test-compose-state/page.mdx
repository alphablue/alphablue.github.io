<h2 id="question">하나의 질문에서 시작하기</h2>

버튼을 한 번 눌렀습니다. 화면의 숫자는 달라졌지만, 그 사이 어떤 코드가 실행되었는지는 아직 모릅니다. 앞으로의 Compose 글은 이런 작은 장면에서 출발하려고 합니다. 눈에 보이는 변화와 내부에서 일어난 일을 따로 적고, 둘을 연결하는 설명을 찾아갑니다.

이 문단은 긴 글을 읽을 때의 줄 길이와 행간을 확인하기 위한 테스트 본문입니다. 한 문장에 개념을 너무 많이 담기보다, 질문 하나를 설명하는 데 필요한 만큼 문단을 나누는 구성을 가정했습니다. 실제 글을 작성할 때는 여기에 문제를 발견한 상황과 확인하고 싶은 조건이 들어갑니다.

> 버튼을 누른 뒤, 어떤 부분이 다시 실행될 것이라고 예상하나요?

답을 먼저 보여주기보다 독자가 잠깐 예상해 볼 자리를 둡니다. 이후 코드와 관찰 결과를 읽었을 때 처음 생각과 무엇이 달라졌는지 비교할 수 있도록 구성할 예정입니다.

<h2 id="example">작은 코드로 범위 좁히기</h2>

아래는 코드 블록의 색상과 들여쓰기, 파일 이름을 확인하기 위한 예시입니다. **실행 검증 전의 표시용 코드**이며, 이 글에서는 동작 결과를 주장하지 않습니다. 실제 원고에는 필요한 import, 사용한 버전, 실행 가능한 예제 링크를 함께 넣을 예정입니다.

```kotlin title="CounterSample.kt"
@Composable
fun CounterSample() {
    var count by remember { mutableIntStateOf(0) }

    Column {
        Text(text = "Count: $count")
        Button(onClick = { count += 1 }) {
            Text(text = "Increase")
        }
    }
}
```

본문 안의 `remember`, `count`, `onClick`처럼 짧은 코드가 한글 문장 사이에 들어오는 경우도 확인합니다. 코드 블록을 읽고 다시 설명으로 돌아왔을 때 자연스럽게 이어지는지가 중요합니다. 모바일에서 긴 줄은 코드 영역 안에서 가로로 넘겨 볼 수 있습니다.

<Callout>
실제 글에서는 관찰 결과와 해석을 구분합니다. 로그만으로 확인할 수 있는 범위와 추가 실험이 필요한 범위를 함께 기록할 예정입니다.
</Callout>

<h2 id="observation">예상과 관찰을 나란히 놓기</h2>

테스트 표에는 실제 측정값 대신 기록할 항목을 넣었습니다. 결과를 채울 때는 재현 순서가 같은지, 개발 환경이 달라지지는 않았는지 먼저 살펴볼 예정입니다.

| 확인할 장면 | 먼저 적을 예상 | 나중에 남길 근거 |
| --- | --- | --- |
| 화면에 처음 진입했을 때 | 어떤 코드가 실행될까? | 실행 환경과 관찰 기록 |
| 버튼을 한 번 눌렀을 때 | 어디까지 영향을 받을까? | 조건을 고정한 재현 결과 |
| 다른 상태를 변경했을 때 | 이전 결과와 같을까? | 차이가 생긴 조건과 추가 질문 |

표는 내용을 빠르게 비교할 때 사용하고, 이유를 설명할 때는 다시 문단으로 돌아옵니다. 모든 정보를 표에 넣으면 긴 설명을 읽기 어려워질 수 있으므로, 비교해야 하는 항목만 추려 놓는 형태를 생각하고 있습니다.

### 결과 다음에 설명을 붙이기

관찰을 마친 뒤에는 공식 문서와 소스에서 설명을 찾습니다. 독자가 실행 결과를 먼저 보고 원리를 따라갈 수 있도록, 근거와 해석 사이의 연결이 끊기지 않는 순서를 목표로 합니다. 아직 설명하지 못한 부분은 다음 실험의 질문으로 남겨둘 수 있습니다.

<h2 id="application">앱의 문제로 돌아오기</h2>

예제에서 이해한 내용을 실제 화면에 적용할 때 어떤 판단이 달라지는지 정리하는 자리입니다. 코드를 짧게 만드는 선택인지, 상태의 책임을 명확하게 만드는 선택인지, 측정해야 답할 수 있는 문제인지 구분해 보려고 합니다.

- 처음의 문제 상황을 다시 한 문장으로 적습니다.
- 실험으로 확인한 범위 안에서 적용할 수 있는 선택을 정리합니다.
- 적용하기 어려운 조건과 아직 확인하지 않은 부분을 함께 남깁니다.
